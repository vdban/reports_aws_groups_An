**On this page**, an overview of **Lê Hoàng Phúc**'s internship worklog over **8 weeks**, from **08/06/2026** to **31/07/2026**, on the **SmartHome_IoT** project. I own **ESP32 firmware**, **MQTT** integration (Adafruit IO and **AWS IoT Core**), **sensor** reads (DHT temperature/humidity, LDR light), and **actuator** control (relay fan/light/door) on a breadboard.

Alongside onboarding and AWS learning (account, IAM, VPC, EC2, IoT Core, CloudWatch), I focused on the **device-to-cloud** path: Thing/certificate setup, `smarthome/` topics, sensor publishing, and command handling including Pomodoro from the dashboard. From **week 6** I started hands-on firmware work; **weeks 7–8** completed end-to-end integration, MQTT reconnect fixes, and a firmware README with pinout/flash steps.
