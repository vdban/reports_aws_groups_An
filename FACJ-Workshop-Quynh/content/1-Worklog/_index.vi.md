**Trong trang này**, em tổng hợp nhật ký công việc trong suốt kỳ thực tập **SmartHome_IoT** tại FCAJ. Kỳ thực tập kéo dài **8 tuần**, từ **08/06/2026** đến **31/07/2026**. Em đảm nhiệm vai trò **Frontend** — thiết kế giao diện trên **Figma**, xây dựng **React dashboard** và triển khai **S3 static hosting**. Song song với dự án, em học các dịch vụ AWS cần thiết cho frontend (tài khoản dùng chung, IAM, VPC, EC2, S3, Cognito) để hiểu cách dashboard kết nối với backend và triển khai lên cloud.

Dưới đây là nội dung công việc theo từng tuần:

**Tuần 1:** [Onboarding, đề xuất ý tưởng dashboard trong họp nhóm](1.1-week1/)

**Tuần 2:** [Tài khoản AWS dùng chung, thử nghiệm S3 static hosting cho React](1.2-week2/)

**Tuần 3:** [IAM cơ bản, nghiên cứu Cognito cho màn hình đăng nhập](1.3-week3/)

**Tuần 4:** [VPC (học chung), wireframe dashboard trên giấy](1.4-week4/)

**Tuần 5:** [EC2 — hiểu API endpoint để tích hợp frontend](1.5-week5/)

**Tuần 6:** [S3 deep dive + thiết kế Figma UI (sensor cards, control panel, Pomodoro, cảnh báo cửa)](1.6-week6/)

**Tuần 7:** [React/Vite, kết nối backend API, luồng đăng nhập Cognito](1.7-week7/)

**Tuần 8:** [Deploy frontend (S3/Amplify), polish UI, chụp screenshot demo cho báo cáo](1.8-week8/)
