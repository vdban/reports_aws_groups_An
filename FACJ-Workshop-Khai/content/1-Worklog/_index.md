**On this page**, an overview of the internship worklog. The internship lasts **8 weeks**, from **08/06/2026** to **31/07/2026**. I joined as **Backend Node.js** developer for **SmartHome_IoT** — responsible for `server.js`, REST API, Lambda, API Gateway, and DynamoDB repository layer. I learned AWS fundamentals (CLI, IAM, VPC, EC2, S3, CloudWatch) in parallel with backend implementation. From **week 6 to week 8**, I built the data layer, serverless endpoints, MQTT bridge, and deployed the API on EC2.
