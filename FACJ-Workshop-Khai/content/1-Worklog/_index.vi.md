**Trong trang này**, tổng quan nhật ký công việc thực tập **8 tuần**, từ **08/06/2026** đến **31/07/2026**. Em tham gia vai trò **Backend Node.js** cho dự án **SmartHome_IoT** — phụ trách `server.js`, REST API, Lambda, API Gateway và tầng repository DynamoDB. Em học AWS (CLI, IAM, VPC, EC2, S3, CloudWatch) song song với triển khai backend. Từ **tuần 6 đến tuần 8**, em xây data layer, serverless endpoints, MQTT bridge và deploy API lên EC2.

Nội dung theo từng tuần:

**Tuần 1:** [Onboarding, lập nhóm, clone & phân tích `backend/server.js`](1.1-week1/)

**Tuần 2:** [Cài AWS CLI, test `aws sts get-caller-identity`](1.2-week2/)

**Tuần 3:** [IAM custom policy — DynamoDB + IoT publish](1.3-week3/)

**Tuần 4:** [VPC Security Group — mở port 3000/8080 cho API](1.4-week4/)

**Tuần 5:** [EC2 — cài Node.js, chạy backend local, IAM Role](1.5-week5/)

**Tuần 6:** [DynamoDB single-table schema, S3 env assets, CloudWatch logs](1.6-week6/)

**Tuần 7:** [Lambda + API Gateway REST, MQTT bridge, test Postman](1.7-week7/)

**Tuần 8:** [Deploy backend EC2, fix bug, viết API README](1.8-week8/)
