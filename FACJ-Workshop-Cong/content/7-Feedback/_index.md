> Personal sharing after **8 weeks** with First Cloud Journey (FCJ), working on **SmartHome_IoT**.

### Overall assessment

**1. Learning & working environment**

FCJ’s weekly structure from foundations to project work helped me learn AWS topics with labs, then apply them to a real IoT + web system instead of isolated exercises only.

**2. Mentor / admin support**

Mentors encouraged debugging independently. That habit helped when integrating MQTT, backend automation, and AWS deploy steps for SmartHome_IoT.

**3. Fit with personal goals**

I started with limited cloud experience. The program covered account setup, Budgets, IAM, VPC, EC2 roles, S3, RDS, CloudWatch, and CLI — then connected those skills to SmartHome_IoT research, build, and deploy.

**4. Skills development**

Building and deploying SmartHome_IoT taught end-to-end thinking: devices → broker → backend → data → dashboard → cloud operations.

**5. Team culture**

Our team coordinated meetings, divided frontend/backend/IoT/AWS tasks, and kept progress notes so everyone stayed aligned.

### Other questions

- What are you **most satisfied** with?
  **Answer:** Taking SmartHome_IoT from topic selection through AWS-backed deploy/demo, not only theory labs.

- What should the company **improve** for future interns?
  **Answer:** More small-group review slots would help when teams hit integration blockers (MQTT/credentials/deploy).

- Advice for the next cohort?
  **Answer:** Enable Budgets on day one, never commit secrets, and stop EC2/RDS after every demo.
